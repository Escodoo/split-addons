Publish the Split Academy catalog on the native eLearning app.

The module adds public Course and Workshop channels, catalog tags (type,
skill, language) and a CRM **Academy** tag so Intake leads can be marked
as academy interest. Installing it also installs ``website_slides``.

Usage
=====

Open **eLearning** to edit the Academy courses, lessons and tags.

The public catalog is at ``/slides``. The website **Courses** menu
points there. Featured course **The Art of Creating Backgrounds**
includes About, Instructor and a members-only practice lesson.

In **CRM**, apply the **Academy** tag on Intake leads that come from
course interest.

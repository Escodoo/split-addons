Publish the Split Academy site and course catalog.

The module creates a second website (**Split Academia**) with Home,
About, Educators and Contact pages, binds the public Course and
Workshop channels to it, and keeps ``/slides`` off the studio site.
Catalog tags (type, skill, language), official cover images and sample
lessons (About, instructor and a members-only practice brief) ship
with the module. Contact form leads go to the Intake team. A CRM
**Academy** tag marks Intake leads that come from course interest.
